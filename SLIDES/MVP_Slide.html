MVP Overview - "Need it By?" Delivery Scheduler
Helping high-intent wishlist users confidently commit to a purchase before leaving the app
What it does :
The "Need it By?" feature embeds directly into the existing Myntra Wishlist, transforming it from a passive bookmarking area into an active scheduling tool. It allows users to declare their delivery deadline, surfaces real-time logistics feasibility, and builds the certainty needed to convert hesitation into a purchase without checking competitor apps.
High Level Flow Diagram :
1
Passive Wishlist Entry
User browses and adds items to the wishlist. The "Need it by a specific date?" prompt is injected natively above the 'Move to Bag' button.
▶
2
Date Selection Modal
User taps the prompt and opens a 7-day schedule modal. They select their hard deadline. Options show dynamic pricing (Standard vs +₹99).
▶
3
Logistics Validation
System checks item stock at the nearest fulfillment center against logistics capacity to validate if the requested date is possible.
▶
4
Guaranteed Date Confirmed
Wishlist card updates in real-time. Ambiguity is resolved. User sees a green "Delivery on [Date]" badge. Confidence is built.
▶
5
Urgency Hook & Buy
A 15-minute countdown timer appears to secure the delivery slot. Scarcity hooks the user to click "Move to Bag" and checkout immediately.
Tech Stack :
Next.js + React • Tailwind CSS • Vercel Deployment
• Custom JSON data array simulating Myntra API delivery validation logic for standard vs expedited dates.
