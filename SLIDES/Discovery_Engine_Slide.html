How Themes Are Generated
The Labelling Approach — Stages 1, 2 & 3
Raw reviews are narrowed by keyword relevance and length filter, then passed to the Groq LLM which acts as a tag-labeller only — not a content generator.
The Enum System
LLM maps each signal to 35 predefined enums across 4 dimensions:
Evidence Types
Decision Drivers
Purchase Contexts
User Segments
The Guardrail
LLM cannot create new tags. Pydantic schema rejects any value outside the predefined list — enforcing zero hallucination at the taxonomy layer.
